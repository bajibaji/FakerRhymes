## 核心硬核功能

### 1. 超级中文押韵词典 (2,088,975 词)
我们并行清洗并合并了 10 个大型语料库（包括新华成语、唐诗宋词、ACG萌娘热词、电影字幕、网络俚语等），总词汇量高达 208 万！是目前最全面、最硬核的中文押韵字库。

### 2. Rust WebAssembly 加速 + 双模二进制二分检索引擎 (微秒级响应)
项目采用了自主研发的 **Rust/WASM + JS 双模二分检索引擎**：
* **WASM 极速黑科技**：核心匹配算法使用 **Rust** 重新编写，通过 WebAssembly (wasm-bindgen) 在底层直接读取内存连续的字节切片指针偏移量。针对“最松模式”的多键批量检索，提供了 `query_exact_batch` 和 `query_suffix_batch` 接口，避开了 JS 层反复解构字符串及 `String.fromCharCode` 的 GC 停顿，运行效率相比纯 JS 二分又提升了数倍！
* **自动降级保护 (Auto Fallback)**：万一在不支持 WebAssembly 的古董浏览器中，代码会自动且无缝地回退到纯 JS 实现的 TypedArray 二进制二分查找和前缀范围扫描，保证 100% 页面可用性。
* **Cloudflare 适配与分片加载**：将 46.8MB 的词典包切分为均小于 25MB 的 `dict_part1.bin` 与 `dict_part2.bin`，**突破 Cloudflare Pages 单文件 25MB 上传限制**。前端并发拉取后在 5ms 内通过 `Uint8Array.set` 在内存中极速合并。
* **极小网络传输**：通过静态资源与 bin 包的 Gzip / Brotli 压缩，首次网络加载仅需 **6MB - 8MB**，并全面支持 PWA 离线使用（包括 WASM 本地预缓存）。

### 3. 歌词热词“淡粉色”高亮 + 优先排布
* **歌词灵感优先**：如果匹配出的词是来自海量经典说唱或流行歌词的词汇，生成器会为它们套上精美的淡粉色高亮皮肤，并自动优先排序在最前方。
* **双语兼容**：一击命中那些最能带起节奏的歌词热词！

### 4. 智能随机去重 (告别无用词刷屏)
我们加入了智能去重算法：在“更多匹配结果”中，如果是字数相同且结尾2个字一样的词（例如：“去极乐”、“到极乐”、“入极乐”），系统会自动随机保留其中一个展示。
这极大地拓宽了结果的多样性，把宝贵的显示区域留给更多不同意象的词汇！

### 5. 押韵盲区完美修复 (“油求辙”互押)
以前由于拼音编码缺失，像“九 (jiu)”、“流 (liu)”、“秋 (qiu)”、“求 (qiu)”等极其常用的字在押韵时会失效。新版本中，我们对词库进行了 100% 纯净规范化重构，现在它们能与“手 (shou)”、“口 (kou)”等油求辙字词完美互通押韵！

## 创作者的高级玩法

### 韵脚宽松度调节
* **严格 (0.0)**：声调完全一致，韵母完全相同（适合格律诗或完美强迫症）。
* **中等 (0.5)**：声调一致，韵母放宽。自动打通前鼻音与后鼻音（如 `an` 与 `ang`）、平舌与翘舌（如 `z` 与 `zh`）。
* **最松 (1.0)**：忽略声调限制，韵母极限放宽（适合说唱自由双押、多押）。

### 平仄过滤 (仅限“最松”模式)
* **全部**：展示所有声调结果。
* **平 (Ping)**：仅展示一声（阴平）和二声（阳平）的词。
* **仄 (Ze)**：仅展示三声（上声）和四声（去声）的词。
* *古风词作、对联创作的绝佳帮手！*

### AI 脑洞大开模式 (Gemini 联想)
嫌固定词库不够刺激？勾选 "AI 押韵模式"，在设置中填入你的 Gemini API Key。
AI 会打破词库边界，为你生成极具现代感、网络梗或意象化的脑洞押韵词！支持 HTTP/SOCKS 代理设置。

### 个人专属自定义词库
点击右上角“自定义词库”，录入你自己的口头禅、新造词或团队专属词，它们会立即保存到浏览器缓存中并参与到以后的押韵计算中！

## 快速上手 (三步起飞)

1. **载入词库**：首次打开，点击页面顶部的“加载词库”按钮（只需并发加载并拼装一次分片包，下次使用自动离线秒开）。
2. **输入词语**：在“请输入要押韵的词语”中输入，例如“人工智能”，按 `Ctrl + Enter` 或点击“生成押韵”。
3. **调音台修正**：在结果下方会显示你输入的字的拼音和声调。如果遇到多音字（如“行”），只需在表格下拉菜单里改一下读音，系统会自动更新匹配结果！

## 常见问题 (FAQ)

**Q: 为什么输入词语后显示“没有找到结果”？**
A: 说明当前匹配太严格了，请尝试将“韵脚宽松度”滑块往右拖动调松，或者检查是否输入了过于生僻的字符。

**Q: 刚更新了代码，但是页面看起来没有变化，或者生成的词语里有杂乱的星号？**
A: 这是因为浏览器缓存了老版本的 main.js 或 Service Worker。请在页面上按下 **Ctrl + F5** 进行强刷，或者在控制台注销 Service Worker 缓存，即可正常加载最新的 **v2.4.0** 二进制版。

**Q: 开发者如何更新词典、编译 WASM 和运行性能跑分？**
A: 本地或云端有一键处理方案：
* **构建二进制字典**：在根目录下运行 `node js/build_dict.js`，脚本会自动读取 `原始数据/` 目录下的两个原始 txt 文件并编译输出分片包 `dict_part1.bin` 与 `dict_part2.bin`。
* **编译 WASM 检索组件**：本项目配置有 GitHub Actions 云端编译工作流，推送时会自动编译并生成 WASM。若在本地，请进入 `wasm-search/` 目录，安装 `wasm-pack` 后运行 `wasm-pack build --target web --out-dir ../js/pkg` 将编译好的胶水和 wasm 输出到项目 `js/pkg/` 中。
* **算法性能跑分**：在根目录下运行 `node js/benchmark_node.js`，可在控制台对当前二进制二分查找和范围扫描算法进行微秒级性能跑分。此外，还可以通过浏览器控制台运行 `window.fakerRhymesPerformanceTests.runCoreTest()` 进行前台检索延迟的真机跑分。
